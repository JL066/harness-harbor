# Harness Harbor for macOS v1.1.2

Harness Harbor v1.1.2 updates the macOS release with the latest worker routing defaults, clearer runtime visibility, and a synchronized 1.1.2 app/runtime stack.

## What's new

- **Updated Codex worker defaults**
  - Default worker: `gpt-6-luna` with `max` reasoning.
  - Supervisors may explicitly select `gpt-6-sol` for unusually difficult tasks or `gpt-6-astra` for exceptional supervisor-level reasoning.
  - Harbor itself does not automatically escalate models.
- **Version visibility in the macOS Dashboard**
  - The Dashboard now displays both the Harness Harbor app version and connected runtime version.
  - This makes app/runtime mismatches easier to identify during development and troubleshooting.
- **Full v1.1.2 version synchronization**
  - macOS app, Python runtime, launcher metadata, packaging paths, and bridge compatibility checks are aligned on `1.1.2`.
  - The native bridge validates the expected runtime version before accepting the connection.
- **Existing macOS credential protections retained**
  - Credentials remain stored in private local credential files.
  - Route-specific secrets are loaded only when required rather than during normal startup.
