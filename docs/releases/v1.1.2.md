# Harness Harbor v1.1.2 — Source Update

This is the v1.1.2 source update. The latest currently published macOS binary remains **v1.1.0-preview.1**. This update does not publish a new DMG or notarized release.

## Highlights

- Codex default worker routing now uses `gpt-6-luna` with max reasoning.
- Supervisors may explicitly select `gpt-6-sol` for unusually difficult work or `gpt-6-astra` for exceptional supervisor-level reasoning. Harbor itself does not auto-escalate.
- The macOS Dashboard now shows the app version and runtime version.
- macOS credential handling retains the private local credential-file design and avoids launch-time Keychain credential reads; route-specific secrets are read lazily.
- Public sync preserves the existing sanitized/public credential implementation and public-history boundaries.
